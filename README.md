# 🎓 Student Management System (SQL Project)

This project showcases SQL skills including database design, table creation, relationships, queries, views, stored procedures, and aggregation.

## 📁 Features
- Student registration  
- Course management  
- Student-course enrollment  
- Marks recording  
- Student performance analytics  
- Views & stored procedures  

## 📂 Project Files
- `create_tables.sql` → Creates database & inserts sample data  
- `queries.sql` → Contains analytics and reporting queries  

## 🛠️ Technologies Used
- MySQL  
- SQL Queries  
- RDBMS concepts
